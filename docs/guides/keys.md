# Keys

Press `?` in the editor (outside a text field) to show this table there. `Cmd` means `Cmd` on a Mac
and `Ctrl` on Windows and Linux.

## Setups

| Keys | Action |
| --- | --- |
| `↑` `↓` | Select the previous or next setup |
| `Home` `End` | Select the first or last setup |
| `F2` | Rename the selected setup |
| `Enter` `Esc` | Keep the new name, or leave it as it was |

## Groups

| Keys | Action |
| --- | --- |
| `(` `)` | Previous or next encoder group |
| `{` `}` | Previous or next fader/button group |
| `Option` + `←` `→` | Step the group of the selected control |
| `Shift` + click | On encoder *n*: encoder group *n*. On green button *n*: fader/button group *n* (as on the UC4) |
| `Shift` + `Enter` | The same, on the focused encoder or green button |

## Controls

| Keys | Action |
| --- | --- |
| `←` `↑` `→` `↓` | Move between controls |
| `Enter` `Space` | Edit the focused control |
| `Esc` | Leave edit mode |
| `Tab` | Move to the next area |

## Copy and paste

| Keys | Action |
| --- | --- |
| `Cmd` + `C` | Copy the setup, group or control in the area you work in |
| `Cmd` + `V` | Paste it onto the one you work on |
| `y` | Copy (only with the Vim keys on) |
| `p` | Paste (only with the Vim keys on) |
| `Esc` | Cancel pasting; `Esc` again leaves edit mode |

## Dialogs

| Keys | Action |
| --- | --- |
| `Esc` | Close a question or panel; nothing changes |
| `Tab` `Enter` | Move to a button, press it |

## Send

| Keys | Action |
| --- | --- |
| `Esc` | Close the Send or Restore window; nothing is sent until you press Send or Restore |
| `Esc` | Close the guide for sending a dump from the device; nothing is sent |

## Tour

| Keys | Action |
| --- | --- |
| `←` `→` | Previous or next step |
| `Esc` | End the tour |
| `Esc` | Not now: close the welcome card |

## Anywhere

| Keys | Action |
| --- | --- |
| `Cmd` + `Z` | Undo |
| `Shift` + `Cmd` + `Z` | Redo |
| `Cmd` + `,` | Open or close Settings |
| `?` | Show these keys (outside text fields) |
